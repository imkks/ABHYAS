# Audio Assets for Abhyas

This directory contains the audio cues and guided practice audio tracks referenced by the application.

## System Sound Cues
- `bell_start.mp3` - Bell tone marking the start of a practice session
- `bell_end.mp3` - Bell tone marking completion of a practice session
- `bell_transition.mp3` - Subtle chime indicating phase transition (Puraka -> Kumbhaka -> Rechaka)
- `tick.mp3` - Matra rhythmic pulse click

## Guided Tracks (Referenced in CONTENT_REQUIREMENTS.md)
- `yoga_nidra_20min.mp3` - 20 minute guided Yoga Nidra track
- `yoga_nidra_30min.mp3` - 30 minute guided Yoga Nidra track
- `yoga_nidra_45min.mp3` - 45 minute guided Yoga Nidra track
- `om_chanting.mp3` - Traditional OM chanting
- `gayatri_mantra.mp3` - Gayatri Mantra chant
- `patanjali_invocation.mp3` - Patanjali Invocation chant
- `guru_vandana.mp3` - Guru Vandana chant
- `shanti_path.mp3` - Shanti Path chant
